A sample command-line application with an entrypoint in `bin/`, library code
in `lib/`, and example unit test in `test/`.

Это бот для продажи 3D-напечатанных аксессуаров через Telegram. Ассортимент включает брелки с тематикой K-pop и пуговицы.
Основная цель бота - обеспечить удобный, быстрый и автоматизированный канал продаж 3D-напечатанных изделий через Telegram без необходимости использования сторонних платформ. 
Задачи бота:
1.	Презентовать каталог продукции с описанием, фото и ценами.
2.	Принимать заказы на стандартные модели.
3.	Уточнять параметры заказа: количество.
4.	Согласовывать условия доставки и способ оплаты.
5.	Предоставлять информацию о статусе заказа.
6.	Собирать отзывы и предложения от клиентов.
7.	Поддерживать базовую техническую поддержку (FAQ, контакты продавца).

Алгоритм работы бота и основные диалоги.
        1)	Основной диалог с пользователем (/start)
Текстовое описание:
1.	Пользователь отправляет команду /start.
2.	Бот проверяет, новый ли пользователь в базе данных.
3.	Если пользователь новый:
o	Регистрирует пользователя в базе.
o	Отправляет приветственное сообщение с описанием возможностей.
o	Показывает главное меню с Reply-клавиатурой.
4.	Если пользователь существует:
o	Отправляет персонализированное приветствие.
o	Показывает главное меню.
5.	Бот ожидает выбора действия от пользователя.
        2)	Оформление заказа
Текстовое описание:
1.	Пользователь выбирает товар из каталога. 
2.	Бот запрашивает параметры:
o	Количество.
3.	Бот рассчитывает стоимость на основе выбранных параметров.
4.	Пользователь подтверждает заказ или вносит изменения.
5.	При подтверждении:
o	Бот генерирует уникальный номер заказа.
o	Сохраняет заказ в базе данных.
o	Отправляет инструкции по оплате.
6.	Бот ожидает подтверждения оплаты.
        3)	Помощь (FAQ)
Текстовое описание:
1.	Пользователь выбирает "Помощь" из меню.
2.	Бот показывает ответы на часто задаваемые вопросы.
3.	Если вопрос не найден, предлагает связаться с продавцом.
